## 📌 Deskripsi Aplikasi
Aplikasi ini membantu pengguna melihat rekomendasi game populer, kategori game, dan persyaratan sistem (*Minimum System Requirements*) sebelum memainkannya[cite: 1, 2]. Data yang digunakan berupa data dummy berstruktur JSON-ready sehingga siap dihubungkan ke REST API pada pengembangan berikutnya[cite: 1].

---

## 📱 Daftar Halaman & Fitur
1. **Beranda (`HomePage`)**: Menampilkan salam, pencarian, ikon kategori game, game populer (scroll horizontal), dan game terbaru[cite: 2].
2. **Daftar Game (`GameListPage`)**: Katalog lengkap seluruh game dengan tombol navigasi "Baca Info"[cite: 2].
3. **Detail Game (`GameDetailPage`)**: Halaman detail yang menampilkan gambar banner, deskripsi, dan tabel Minimum System Requirements[cite: 2].
